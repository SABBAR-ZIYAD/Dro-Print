# LinkedIn post draft

Last year, during a two-month internship, I built DroPrint, a web platform for a printing business in Marrakech. The original Laravel application let customers explore print products and request custom quotes, while staff managed products, categories, and announcements through Filament.

I have since modernized it into a React customer site backed by a Laravel API. The full journey now covers category browsing, product details and related products, search, and quote requests with artwork uploads. I also packaged the stack with Docker and added CI checks for the frontend, backend, and running containers.

This project taught me how to turn a real business need into an end-to-end application, and how to improve an existing system without losing its useful workflows.

GitHub: https://github.com/SABBAR-ZIYAD/Dro-Print
